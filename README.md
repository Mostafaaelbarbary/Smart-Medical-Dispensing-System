# Smart-Medical-Dispensing-System
Designed and developed an automated medication dispensing system using embedded systems.
Integrated ESP microcontroller for user notifications and real-time alerts.
Implemented Real-Time Clock (RTC) module for scheduled medication reminders.
Built a multi-drawer mechanism to organize and dispense different medicines.
Developed user interface with LCD display and keypad for confirmation input.
Added buzzer alerts and remote messaging to ensure timely medication intake.
